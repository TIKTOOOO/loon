# 设置虚拟位置：苹果地图 / 高德地图分享快捷指令

当前交付为完整动作配置说明。Windows 无法使用 Apple 的快捷指令签名工具，尚未生成已签名安装文件或 iCloud 分享链接；不能把 JSON 或未签名 plist 当成可安装的快捷指令。需要在 iPhone 上按以下动作创建一次，然后可通过 iCloud 分享已创建的快捷指令。

## 创建与首次配置

在 iPhone「快捷指令」中新建，名称 **设置虚拟位置**；详情打开「在共享表单中显示」，输入类型选 **URL、文本、地图链接/位置**（实际可选名称随系统变化）。

在顶部加入两个「文本」动作，分别设为自己的 Worker HTTPS 地址（不带尾斜杠）和 TOKEN，分别「设定变量」为 `服务地址`、`口令`。在编辑器中只在手机填写，公开说明与可分享模板留空；个人版带口令时不可公开分享。快捷指令中的口令为本机配置，不是安全钥匙串。

可在详情的「设置问题/导入问题」中为这两个文本动作添加提示「你的 Worker 地址」「你的访问口令」，供导入时填写。

## 逐个添加动作

下面每个编号是一段按顺序排列的动作；变量使用快捷指令的魔法变量，不要把方括号当作普通字符串输入。

1. **如果**「快捷指令输入」有任何值：用「从输入获取 URL」读取快捷指令输入，然后「获取列表中的项目」选第一个，设变量 `分享内容`。如果没有 URL，改用「从输入获取文本」设为 `分享内容`。
2. **否则**：添加「从菜单中选取」，提示「没有地图分享输入，是否读取剪贴板？」；选项「读取剪贴板」下使用「获取剪贴板」→「从输入获取文本」→设定 `分享内容`；选项「取消」下使用「停止此快捷指令」。结束菜单、结束如果。系统若询问粘贴权限，由用户决定。
3. **匹配文本**：输入 `分享内容`，模式 `https?://[^\s<>"，。；）)]+`。**如果**匹配结果没有任何值：显示提醒「请在苹果地图或高德地图选点 → 分享 → 设置虚拟位置」，然后「停止此快捷指令」。结束如果。
4. **文本**：`[服务地址]/api/parse` →「URL」→ **获取 URL 内容**，展开设置：方法 **POST**；请求头 `Authorization` = `Bearer [口令]`，`Content-Type` = `application/json`；请求正文选 **JSON**，添加文本字段 `text` = `分享内容`、`datum` = `auto`。将结果「获取输入的词典」，设为 `解析结果`。网络连接失败会由系统停止，不能继续保存。
5. **获取词典值** `ok`（词典为 `解析结果`）；**如果**不是布尔值「真」：获取 `error` →「显示提醒」（空则显示「解析失败，原位置未改动」）→「停止此快捷指令」。结束如果。
6. 从 `解析结果` 分别获取 `name`、`source`、`latitude`、`longitude`，设变量 `地点`、`来源`、`纬度`、`经度`。将纬度、经度分别用「从输入获取数字」转换为数字，并各取第一个数字，重新设定变量，避免发送为 JSON 字符串。
7. **显示提醒**，标题「确认目标位置」，内容「[地点] / [来源]，WGS84：[纬度]，[经度]。确认后仅保存到服务器，手机还需刷新定位。」打开「显示取消按钮」。取消会终止运行；确认后才执行下一步。
8. **文本** `[服务地址]/set` →「URL」→ **获取 URL 内容**；方法 **POST**，请求头与步骤 4 相同；JSON 正文字段 `lat` 类型选 **数字**、值 `纬度`，`lng` 类型选 **数字**、值 `经度`。将结果转词典，设为 `保存结果`。
9. 获取 `保存结果` 的 `ok`；**如果**不是布尔值「真」：读取 `error` →显示提醒「保存失败，未确认更新」→「停止此快捷指令」。结束如果。再获取 `status`，**如果**不是文本 `saved`：显示提醒「未收到保存确认，请重试」→停止。结束如果。
10. **显示提醒**：「服务器已保存。Loon 在新的定位请求中读取配置；Cloudflare 数据传播和 iOS 缓存可能延迟生效，请检查日志中的坐标。请手动关闭再开启定位服务，再打开地图验证。若未直达设置，请手动进入：设置 → 隐私与安全性 → 定位服务。」
11. **URL**：`App-prefs:Privacy&path=LOCATION` → **打开 URL**。这是需要在 iOS 26.7.1 上验证的设置深链接；它不是已验证的稳定接口，可能只能打开设置或失败。步骤 10 已提供手动路径；失败不重发保存请求。

## 使用与核对

苹果地图：搜索或长按选点 → 地点卡片「共享」→ 设置虚拟位置。
高德：选点 → 分享 → 更多 → iOS 系统分享菜单 → 设置虚拟位置。

选点后核对确认卡片，再保存；保持 Loon 总开关与插件启用，手动关开定位服务后验证。网页和快捷指令写入同一份配置，后保存的操作会覆盖前一次。

自动坐标转换参考来源和地区规则，行政边界附近可能偏移。已经是 WGS84 的坐标不要再按 GCJ02 转换；不确定时用网页「解析预览」的坐标类型选择器核对。

如分享菜单没有快捷指令，先在快捷指令 App 手动运行一次并授予所需权限；再从地图分享，检查「更多」。未解析出具体坐标的 POI 链接会报错，请改用网页点选，不能把地图视野中心当作地点。
